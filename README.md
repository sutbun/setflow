# SetFlow

iPhone用の筋トレ記録PWA。MacBookやApple Developer Programなしで動作します。

## 主な機能
- 種目、重量、回数、休憩時間の設定
- 「セット完了」で記録を端末内に保存、休憩タイマー即開始
- 設定した休憩時間のカウントダウン、±15秒調整
- 前回の重量・回数、今日の記録、日付別・種目別にまとめた履歴（前後の記録日への移動、日付選択）
- JSONファイルによるバックアップと復元
- Google Sheetsへのオンライン同期と再接続
- iPhoneホーム画面から起動、基本操作はオフラインでも可能

## Google Sheets 同期
個人の Google Sheets（記録タブ）へ追記する構成。端末上に記録をまず保存してから同期します。

1. Google CloudでGoogle Sheets APIを有効化
2. Google OAuthのWebクライアントを作成し、承認済みJavaScript生成元に `https://sutbun.github.io` を登録
3. 「設定」でOAuthクライアントIDを一度入力してGoogle接続
4. 接続中はセット完了時、オンライン復帰時、アプリ再表示時に未送信を同期
5. Google認証が失効した場合、トレーニング画面の「再接続」を押すと再認証でき、未同期分が送信されます

OAuthトークンは**メモリ内でのみ保持**し、localStorageに長期保存しません。Google Identity Servicesのブラウザー用トークン方式は、ページ再起動・トークン失効後に利用者操作なしでは再認証できないため、再接続はタップ操作が必要です（Googleの公式仕様）。

Google Sheetはデータ保存先の一つであり、**サーバーから端末への記録復元や種目設定の双方向同期は未実装**。端末内のJSONバックアップを定期的に取ってください。端末内で取り消した同期済みセットはSheetの行に自動反映されません。

## 更新と注意
- Google Sheetsへの同期はインターネットとGoogleの許可が必要。同期できなくてもタイマーと端末内保存は動きます。
- 端末のWebサイトデータ削除でローカル記録が消えることがあります。
- 画面ロック中の音・振動は保証しません。
- トレーニング画面の再接続は認証が切れた時だけ利用してください。
- iPhone実機での検証は必要です。

共通開発ルール: https://github.com/sutbun/ai-dev

## PWAの更新
- 設定画面の「アプリの更新を確認」で `build.json` の最新版を確認する。
- HTMLが参照するJavaScript/CSSにはバージョンクエリを付加し、旧キャッシュにより古い画面が残るのを防止する。
- 初回の更新はSafariで `https://sutbun.github.io/setflow/?v=dev-10.29-5` を開く。
- Googleの接続状態は再起動時に失効することがあるが、端末の記録を消す必要はない。
- リリース時は `APP_VERSION`、`build.json`、HTMLの資産クエリ、SWのキャッシュ識別子を揃えて更新する。

## ホーム画面アイコン
- Safariの「ホーム画面に追加」で、淡いグレーのダンベルアイコンを使用します。
- iOS向けの `apple-touch-icon-20261030.png`（180px）をHTMLで明示指定し、PWA manifestとSVGアイコンも揃えています。
- 既存のホーム画面ショートカットは古いアイコンを保持する可能性があります。必ずJSONバックアップを作成してから再追加してください。
- Webアプリの保存データは削除しないでください。ホーム画面のアイコンを削除すると、PWA内のデータが失われる場合があります。

## DEV-10.31-1 — 体組成管理
- 新しい「体組成」タブで体重・体脂肪率・筋肉量・BMIの最新値と推移を閲覧。測定日時ごとの全20項目も確認できます。
- 測定の追加・編集・削除に対応。端末内に先に保存し、接続中にGoogleスプレッドシートと同期します。
- 既存の「体組成測定履歴」（測定履歴タブ）を保存先として使います。筋トレ用の「SetFlow 筋トレ記録」とは別ファイルで、既存データを複製しません。
- Googleへの接続が必要なときは「設定」で再接続してください。同期には既存のSheets API権限を使用します。
- 体組成データもSetFlowのJSONバックアップに含めます。古いバックアップを読み込んでも、バックアップに体組成が含まれなければ既存の体組成記録を保持します。
- 別端末での同時編集には競合解決の制限があります。同期済み行を直接Google側で削除した場合も、他端末へ削除状態は完全には伝搬しません。


## DEV-10.31-3 — 履歴の編集と誤削除対策
- 筋トレの「履歴」で各セットの「編集」をタップすると、重量・回数を直接修正できます。必要な場合だけ種目・日時も変更できます。
- 「今日の記録」の「取消」も編集画面へ移動します。削除は編集画面で確認してから行います。
- 削除は永久消去ではなくごみ箱へ移動します。筋トレは「設定」のごみ箱、体組成は「体組成」画面下部のごみ箱から復元できます。
- Google Sheetsでは筋トレの記録シート I列、体組成の測定履歴 U列に追加した状態欄へ active / deleted を記録します。既存の行は変更せず、修正内容は同じ行を更新します。
- オフラインでもローカル保存し、Google接続中に変更を送信します。旧版の記録はそのまま読み込めます。
- 既存の体組成計の測定値や筋トレ記録を消去せず、ローカル保存キーも変更していません。

## DEV-10.31-4 — 日付別の一括編集モード
- 「履歴」の日付ごとに「編集」ボタンからまとめて編集します。各セットの重量と回数はその場で入力。種目や日時は必要な行だけ開いて変更できます。
- 「＋セット追加」で既存種目の前回値を引き継いだセットを追加。「別の種目を追加」からその日の記録へ種目も追加できます。
- 「保存して終了」までは既存記録を書き換えません。「取消」で作業を破棄でき、編集中は日付移動を無効にします。
- 削除は対象セットを表示して確認後に削除予定とし、保存前の取消と保存後のごみ箱復元に対応します。
- iPhoneの日付／時刻ピッカーは表示と入力を分離し、2列入力の崩れを防ぎます。
- 同期は確定後に行い、Googleシートの同じ記録IDを更新します。端末のローカル保存キーは変更しません。

## DEV-10.31-6 — 常時表示のタイマー
- トレーニング画面の一番上にタイマーを配置。休憩開始前や終了後も `00:00` を表示。
- −15秒、＋15秒、終了の操作ボタンを削除。セット完了で種目設定の休憩時間から自動カウントダウンします。
- 画面を消して復帰した場合も終了時刻から残り時間を再計算します。ロック中の音・振動は保証しません。
